# Prototypes

## ai-datacenter-demo — 이상 상황 진행 단계 관제 데모 (2026-08-27)

GPU 부하 급증 국면에서 위험이 어느 단계까지 진행했고 지금 개입하면 막을 수 있는지를 관제 운영자에게 보여주는 화면 프로토타입.

- 화면: 대시보드(이상 상황 목록 위젯 · σ 센서 모니터링 · 배치도) / 이상 상황 상세(진행 단계 타임라인 · 판단 근거 · 개입 여지) / 조치 이력 기록(4단계 태그 + 예측 판정) / 알림 센터 드로어(상황 단위 번들 알림)
- 상단 "프로토타입 시뮬레이터"로 조건부 UI(확신도 미달 · 냉각 신호 단절 · 계통 미등록 · 작성 중 초안) 트리거 가능
- "설명 모드" ON 후 컴포넌트 우클릭 시 정책 설명 표시

```bash
cd ai-datacenter-demo
npm install
npx vite
```
